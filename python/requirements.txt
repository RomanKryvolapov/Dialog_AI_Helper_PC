# Python 3.14 environment for the Whisper batch + streaming utilities.
#
# faster-whisper runs inference through CTranslate2. On Windows the GPU is used by loading
# the CUDA runtime / cuBLAS / cuDNN DLLs that ship inside torch/lib; the scripts add that
# folder to the DLL search path and fall back to CPU automatically if the GPU is unavailable.
# torch is built for CUDA 12.8 (cu128), which supports Blackwell GPUs (RTX 50xx).
#
# Held back on purpose (checked 2026-11-25 on an RTX 5070 Ti):
# - torch stays at 2.11.0+cu128: it is the last CUDA 12 build for Python 3.14; newer builds ship
#   only CUDA 13 libraries, which CTranslate2 (built against CUDA 12) cannot use.
# - ctranslate2 stays at 4.8.0: 4.8.5 and 4.9.1 fail to load cublas64_12.dll from torch/lib and
#   silently fall back to CPU (several times slower); 4.8.0 runs on the GPU.
# - av stays at 18.1.1: 19 dropped the metadata_errors argument faster-whisper 1.2.1 passes to
#   av.open, so every transcription fails with it.
# - setuptools stays below 82 and mpmath below 1.4: torch 2.11 and sympy 1.14 require that.
#
# The PyTorch CUDA wheels live on a dedicated package index:
--extra-index-url https://download.pytorch.org/whl/cu128
